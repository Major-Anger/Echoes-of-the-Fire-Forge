# Fichiers d'Anger (sources)

Modèles et textures retouchés par Anger dans Blockbench. Ils font foi : le code et les données du jeu en sont tirés.

- `forgemaster/marteau_pilon.bbmodel` : le marteau-pilon du joueur (modèle d'objet « java_block », texture incluse).
- `forgemaster/maitre_de_forge.bbmodel` : le maître de forge (entité « modded_entity », box uv, texture 128 x 128 incluse).
  La couche qui luit (yeux, braise, verres des lunettes) reste celle de `tools/textures/make_forgemaster_textures.py`.
  On garde la ceinture : la pièce `apron` (tablier court) n'est pas reprise dans le jeu.
